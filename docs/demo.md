# Сценарий защиты — 3 минуты

## Подготовка за 10 минут до выхода

1. `run.bat --serve` (с ИИ-письмом: сначала `$env:GEMINI_API_KEY = "..."`, затем `run.bat --serve --llm`).
2. Браузер: вкладка http://127.0.0.1:8000, масштаб 125–150%, включён «Крупный шрифт», если зал большой.
3. В проводнике открыта папка `data` — оттуда перетаскиваем `billing_03.csv`.
4. Запасной вариант без сервера: `run.bat --open` откроет `out/index.html` (семья) и отчёты всех пятерых.
5. Видео-запаска записана заранее; всё работает без интернета (без интернета только шрифты станут системными).

## Три минуты

Главное для жюри: **кто пользуется, какую проблему решаем, как это работает в жизни** — и только потом «пункты ТЗ выполнены».

Никто её не читает — поэтому деньги и уходят. Мы сделали „Где мои деньги?“ — для тех, кто помогает родителям со связью». |

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| Порт 8000 занят | `run.bat --serve --port 8001` |
| Перетаскивание не срабатывает | кликнуть по зоне и выбрать файл, или кнопка профиля «Бабушка» |
| ИИ-письмо не появилось | это нормально: без ключа или сети отчёт с шаблонами; сказать «ИИ включается флагом, числа считает код» |
| Нет ноутбука с проектом | `git clone` + `run.bat` на любом компьютере с Python 3.10+ |
