# Сценарий защиты — 3 минуты

## Подготовка за 10 минут до выхода

1. `run.bat --serve` (с ИИ: сначала `$env:GEMINI_API_KEY = "..."`, затем `run.bat --serve --llm`).
2. Браузер: http://127.0.0.1:8000, ширина окна не меньше 1280 px (чек справа от заголовка), масштаб 110–125%.
3. В проводнике открыта папка `data` — на случай, если жюри попросит загрузить файл.
4. Запасной вариант без сервера: `run.bat` → открыть `out/index.html`. Всё, кроме «Порогов» и «Дубля вживую», работает.
5. Бот (по желанию): `$env:TELEGRAM_BOT_TOKEN = "..."; python analyze.py --bot`, в телефоне открыт чат с ботом, `billing_03.csv` лежит в «Избранном».
6. Перед выходом: `python analyze.py --validate data` → «ИТОГО 5/5 ЗАЧЁТ».
7. Видео-запаска записана заранее. Интернет не нужен (без него только шрифты станут системными).

> Перед выступлением можно открыть `http://127.0.0.1:8000/?autoplay=1` на втором экране или стенде: приложение само проведёт экскурсию по всем экранам. Для живого показа — `/?intro=0`, чтобы приветствие не всплывало.

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| Порт 8000 занят | `run.bat --serve --port 8001` |
| Чек уехал под заголовок | окно уже 1100 px — развернуть браузер или уменьшить масштаб |
| «Объяснить проще» показывает шаблон | это нормально без ключа: «ИИ включается флагом, числа считает код» |
| Сервер не запускается | `out/index.html` — тот же экран на вшитых данных |
| Нет ноутбука с экраном / проектор не работает | телефон: переслать `billing_03.csv` боту → «К возврату: 65,00 сом» и претензия файлом |
| Бот молчит | нет интернета или токена — показываем веб-приложение; бот не обязателен для демо |

## Ответы на вопросы

- **Почему окно из 7 предыдущих дней, а не с текущим?** Иначе всплеск сам поднимает среднее и σ и маскирует себя.
- **Почему не вычитаете дубли из итога?** Деньги реально списаны: отчёт показывает факт, аномалия — что можно вернуть.
- **Почему «к возврату» не равно сумме всех amount_som?** Всплеск дня складывается из тех же списаний — иначе двойной счёт.
- **Почему «новая подписка» — первая в файле, а не по времени?** Так в уточнениях; для дублей наоборот — по времени. Оба случая закрыты fuzz-тестом.
- **Радар не даст ложных срабатываний?** Он только на экране оператора; в `anomalies.json` — строго пять правил ТЗ.
- **Что уходит в ИИ?** Только одна находка с замаскированными номерами (+99677••••26). Ответ с числом, которого нет в фактах, отбрасывается.
- **Как это зарабатывает?** Абоненту бесплатно; семейный режим — подписка; радар — лицензия оператору: меньше жалоб и проверок регулятора.
