# Сценарий защиты — 3 минуты

Показываем живой продукт: сайт **https://akcham.confhub.kg** и бот **[@akchamkaida_bot](https://t.me/akchamkaida_bot)**.
Локальный запуск — только запасной вариант.

## Подготовка за 10 минут до выхода

1. Ноутбук: открыть **https://akcham.confhub.kg/?intro=0** (без приветствия), окно на весь экран, ширина от 1280 px, масштаб 110–125%.
2. Проверить, что сервер жив: https://akcham.confhub.kg/api/health → `"ok": true` и `"llm": "Gemini …"`.
3. Один раз нажать «Объяснить проще» у любой находки, чтобы прогреть ИИ.
4. Телефон: открыт чат с @akchamkaida_bot, файл `billing_03.csv` лежит в «Избранном» Telegram, чтобы переслать в одно касание. Если можно, вывести экран телефона на проектор.
5. Слайд с QR-кодами: [docs/brand/qr-slide.png](brand/qr-slide.png) (сайт и бот).
6. Запасной вариант без интернета: `run.bat --serve` → http://127.0.0.1:8000/?intro=0. Без сервера: `run.bat` → `out/index.html`.
7. На втором экране или стенде можно включить **https://akcham.confhub.kg/?autoplay=1**: приложение само проводит экскурсию по всем экранам.
8. Видео-запаска записана заранее.

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| Нет интернета в зале | `run.bat --serve` → http://127.0.0.1:8000/?intro=0; ИИ покажет шаблон, бот пропускаем |
| Сайт не открывается | `ssh kuma@5.59.233.69` → `docker ps` (контейнер `akcham`), команды в `~/inai-billing-check/deploy/README.txt`; на сцене — локальный запуск |
| «Объяснить проще» показывает шаблон | лимит или нет связи с Gemini: «ИИ — дополнение, числа считает код» |
| Бот молчит | проверить /api/health; на сцене показываем веб-приложение, бот не обязателен |
| Чек уехал под заголовок | окно уже 1100 px — развернуть браузер или уменьшить масштаб |
| Проектор не работает | телефон: сайт по QR-коду или бот |

## Ответы на вопросы

- **Почему окно из 7 предыдущих дней, а не с текущим?** Иначе всплеск сам поднимает среднее и σ и маскирует себя.
- **Почему не вычитаете дубли из итога?** Деньги реально списаны: отчёт показывает факт, аномалия — что можно вернуть.
- **Почему «к возврату» не равно сумме всех amount_som?** Всплеск дня складывается из тех же списаний — иначе двойной счёт.
- **Почему «новая подписка» — первая в файле, а не по времени?** Так в уточнениях; для дублей наоборот — по времени. Оба случая закрыты fuzz-тестом.
- **Радар не даст ложных срабатываний?** Он только на экране оператора; в `anomalies.json` — строго пять правил ТЗ.
- **Что уходит в ИИ?** Только одна находка с замаскированными номерами (+99677••••26). Ответ с числом, которого нет в фактах, отбрасывается. Не больше 20 запросов в минуту с адреса.
- **Где это работает?** Свой сервер в Docker рядом с другим проектом, HTTPS, бот на webhook внутри того же сервиса. Ядро — только стандартная библиотека Python.
- **Как это зарабатывает?** Абоненту бесплатно; семейный режим — подписка; радар — лицензия оператору: меньше жалоб и проверок регулятора.
